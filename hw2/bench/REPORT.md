# Тесты и бенчмарк hw2

Запуск: 12 ноября 2026 года, Windows, MSYS2 UCRT64, GNU C++ 16.2.0,
C++17, Ninja. Конфигурация **Release**, оптимизация **-O2**
(аналог `/O2` в MSVC; для MSVC цель автоматически использует `/O2`).

## Воспроизведение (PowerShell из корня проекта)

```powershell
$env:PATH = 'C:\msys64\ucrt64\bin;' + $env:PATH
cmake --preset release
cmake --build --preset release --verbose
ctest --test-dir build/release -R '^hw2_tests$' --output-on-failure
./build/release/hw2/hw2_bench.exe
```

Существующие presets настроены на GCC из MSYS2. Для другой системы
нужно выбрать свой компилятор и генератор CMake.

Фрагмент фактической команды компиляции бенчмарка:

```text
C:\msys64\ucrt64\bin\c++.exe ... -O3 -DNDEBUG -std=gnu++17 -O2 ... -c C:/Users/User/cpphw/hw2/bench/benchmark.cpp
```

`-O3 -DNDEBUG` добавлены стандартной конфигурацией Release CMake,
а последний `-O2` задан для цели `hw2_bench` и определяет уровень оптимизации.
Бенчмарк печатает конфигурацию и компилятор; запуск в Debug отклоняется.

## Проверки корректности

Для обеих реализаций проверены умножение на единичную и нулевую матрицы
слева и справа, прямоугольный пример 2×3 на 3×2 с ожидаемым результатом
`[[-7, 17], [9, 0]]`, исключение `std::invalid_argument` при несовместимых
размерах, матрицы с нулевыми измерениями.

На случайных матрицах размеров `(m, n, p)`:
`(1,1,1), (2,2,2), (2,3,4), (7,1,9), (1,13,1), (13,7,19), (32,32,32), (64,64,64)`
результаты двух реализаций совпали с абсолютным допуском `1e-9`.
Для каждой формы — три набора данных; seed `12345`.
Проверки остаются активными при `NDEBUG`.

CTest: `hw2_tests` прошёл в Release и Debug. В Debug также прошёл `hw1_tests`.

## Результаты производительности

Среднее трёх запусков на одних и тех же входных матрицах, время в мс.
Элементы равномерно распределены в `[-1, 1]`, seed `12345`.
Порядок запуска реализаций чередуется. Генерация данных и сверка всех
элементов результата с допуском `1e-9` выполняются вне измеряемого участка;
выделение результирующей матрицы входит во время умножения.

| Размер | Наивная, мс | Оптимизированная, мс | Ускорение |
| --- | ---: | ---: | ---: |
| 100×100 | 1.887 | 1.268 | 1.488× |
| 200×200 | 16.100 | 10.348 | 1.556× |
| 500×500 | 252.314 | 164.034 | 1.538× |
| 1000×1000 | 2362.246 | 1322.777 | 1.786× |

Полный вывод сохранён в [results.txt](results.txt).
Числа зависят от оборудования и нагрузки системы; на этом запуске
ускорение составило 1.49–1.79 раза.

Отдельное ограничение существующего проекта: `hw2/main.cpp` пуст,
поэтому сборка цели `hw2_main` завершается ошибкой отсутствующего `main`.
Приведённый Release preset собирает тесты и бенчмарки и не требует этой цели.
Для Debug можно собрать проверки отдельно:

```powershell
cmake --preset debug
cmake --build --preset debug --target hw2_tests hw2_bench
ctest --test-dir build/debug -R '^hw2_tests$' --output-on-failure
```
